# 제안전략 지식시스템 편집기

K드라이브의 레코드를 브라우저에서 읽고 고친다. **저장을 누르면 K: 의 md 파일이 바로 바뀐다.**

## 켜기 — 내 PC에서

`편집기 켜기.bat` 을 두 번 누른다. 브라우저가 알아서 열린다.

```
python server.py
python server.py --port 8778        다른 포트
python server.py --root "D:/사본"    다른 폴더
```

끄려면 검은 창에서 **Ctrl+C**. 창을 닫아도 된다.

파이썬 3.8 이상이면 된다. 설치할 패키지는 없다.

## 켜기 — 서버 한 대에 여러 명이 붙을 때

```
python server.py --host 0.0.0.0 --root "K:/Workgroups/제안전략 지식시스템"
```

그 서버에서 K드라이브가 **마운트돼 있어야** 한다. 접속은 `http://<서버주소>:8777`.

**로그인이 없다.** 망에서 그 포트에 닿는 사람은 누구나 레코드를 고칠 수 있다.
사내망 안에서만 열거나, 앞에 인증 프록시(사내 SSO·리버스 프록시)를 두고 쓴다.
`--host 0.0.0.0` 으로 켜면 서버가 이 경고를 찍는다.

서버가 K드라이브에 쓸 때 쓰는 계정은 **서버를 돌리는 계정 하나**다.
누가 무엇을 고쳤는지는 K드라이브 권한이 아니라 아래 「이름」과 백업으로 남는다.

#### 업데이트 — 아무도 손대지 않아도 된다

서버가 **스스로 최신 코드를 따라간다.** 기동할 때 한 번, 그 뒤로 10분마다 확인한다.

1. `git fetch` 해서 새 커밋이 있는지 본다
2. **편집 중인 사람이 있으면 건너뛴다.** 다음 차례에 다시 본다
3. 받을 게 있으면 `git pull --ff-only` 하고 **스스로 다시 뜬다**
4. 열어 둔 화면은 버전이 바뀐 것을 보고 **알아서 새로 고친다**
   (고치던 중이면 그대로 둔다. 저장하거나 취소한 뒤에 따라간다)

그래서 쓰는 사람은 할 일이 없다. 켜 두면 알아서 최신이 된다.

```
python server.py --host 0.0.0.0 --no-auto-update     스스로 받지 않게
python server.py --host 0.0.0.0 --update-every 1800  30분마다 확인
```

고쳐 둔 파일이 있으면 당기지 않고 건너뛴다. 서버에서는 코드를 직접 고치지 않는 게 좋다.
`git` 으로 받은 폴더가 아니면 자동 갱신은 그냥 꺼진다.

## 이름

편집할 때 다른 사람에게 보일 이름을 한 번 적는다. 머리의 **이름** 단추로 언제든 바꾼다.
브라우저에 저장되고 요청마다 서버로 간다.

이 이름은 **본인이 적는 것이라 신원 증명이 아니다.** 컨플루언스의 「○○님이 편집 중」 과 같은
용도다 — 누가 지금 그 레코드를 잡고 있는지 알리는 이름표.
이름을 적지 않으면 `이름 없음` 으로 잡히고, 그래도 잠금 자체는 정상으로 작동한다.

## 읽기

왼쪽이 K드라이브 폴더 구조다. 레코드를 고르면 **읽기 좋게 그려진 화면**이 나온다.
표·목록·강조가 그대로 보이고, `(확인 필요)` 는 노란색으로 뜬다.

- 각 카테고리 맨 위에 그 카테고리의 **양식**이 있다
- 숫자 배지는 그 레코드에 남은 `(확인 필요)` 개수다. `✓` 면 다 찼다
- **새로 읽기** — 편집기 밖에서 파일을 고쳤을 때 누른다

## 고치기 — 여러 사람이 쓸 때

**「수정하기」를 눌러야 편집 화면으로 바뀐다.** 누르는 순간 그 레코드를 **잠근다.**

- 잠금은 K드라이브 `_편집중` 폴더에 파일 하나로 남는다.
  서버 메모리가 아니라 공유 폴더에 두는 이유는, **각자 자기 PC에서 띄워도 같은 잠금을 보게** 하기 위해서다.
  서버 한 대로 모아 써도 똑같이 작동한다
- 남이 편집 중이면 「수정하기」가 **「편집 중」으로 비활성**되고,
  누가 언제부터 보고 있는지 알려 준다. 트리에도 ✎ 표시가 붙는다
- **저장하거나 취소하면 잠금이 바로 풀린다.** 창을 닫아도 풀린다
- **15분** 동안 아무 신호가 없으면 끊긴 잠금으로 보고 다른 사람이 가져갈 수 있다
  (PC가 꺼졌거나 브라우저가 죽은 경우)
- 급하면 「잠금 가져오기」로 뺏을 수 있다. 확인을 한 번 묻는다
- 잠금을 쥐지 않은 저장 요청은 **서버가 거부한다.** 화면을 우회해도 안 된다

편집 화면에서는:

- **표 칸** — `사업 정보` · `자산 정보` 의 값을 칸마다 고친다
- **섹션** — `수행 내용`, `차별점` 같은 본문을 섹션 단위로 고친다. md 그대로 쓴다
- **섹션 제목과 `> 출처:` 줄은 못 고친다.** 구조가 흔들리면 다른 도구가 레코드를 못 읽는다
- 저장은 **Ctrl+S** 도 된다. 저장하면 읽기 화면으로 돌아온다
- 잠근 뒤 내용을 다시 읽어 온다. 기다리는 동안 남이 고쳤어도 최신 것을 받는다

## 저장할 때 막는 것

아래에 걸리면 **저장하지 않고** 무엇이 문제인지 보여 준다.

- 표 칸 값에 줄바꿈이나 `|` 가 들어간 경우 — 그 행부터 표가 깨진다
- 표 칸 값에 `## ` 가 들어간 경우 — 예전에 이것 때문에 레코드가 통째로 깨진 적이 있다
- 필수 필드가 빠진 경우 (01 은 8개, 02 는 4개, 03 은 3개)
- 표의 열 수가 위아래로 어긋나는 경우
- 같은 이름의 섹션이 둘 이상인 경우
- **파일이 편집기 밖에서 바뀐 경우** — 덮어쓰지 않고 새로 읽으라고 한다

## 안전장치

- **잠금 없이는 저장되지 않는다.** 화면이 아니라 서버가 막는다
- 저장 전 원본을 `_백업/<카테고리>/<레코드>/<날짜-시각>.md` 에 복사한다. 레코드당 30개까지 남는다
- 백업은 **이 폴더 안**에 쌓인다. K드라이브 공유 폴더는 더럽히지 않는다
- 손대지 않은 줄은 한 글자도 바뀌지 않는다. 고친 자리만 갈아 끼운다
- `02`·`03` 의 `기준 시점`·`담당자` 를 고치면 그 카테고리 `index.md` 의 같은 칸도 맞춰 준다
- `127.0.0.1` 에만 붙는다. 같은 PC 밖에서는 열리지 않는다

## 알아 둘 것

- **첫 기동이 15초쯤 걸린다.** K: 가 네트워크 드라이브라 레코드 125건을 처음 훑는 데 시간이 든다. 그 뒤로는 즉시 뜬다
- 이미 켜져 있는데 또 켜면 **포트를 쓰고 있다**고 알려 주고 멈춘다. 옛 서버로 요청이 새는 것을 막기 위해서다
- `_양식_*` 과 `_기입례*` 는 기본으로 숨겨 둔다. 기입례는 가상 레코드라 제안 근거로 쓰면 안 된다
- `04_회사정보` 의 표는 열이 4개라 칸 편집 대상이 아니다. 섹션 본문으로 고친다

## 읽기만 할 때

읽기 전용 열람기를 따로 만들어 두었다. 앱을 켜지 않아도 링크로 열리고, 대신 고칠 수는 없다.
링크는 사내에서 따로 공유한다 — **이 저장소에 적지 않는다.**
