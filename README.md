# 제안전략 지식시스템 편집기

K드라이브의 레코드를 브라우저에서 읽고 고친다. **저장을 누르면 K: 의 md 파일이 바로 바뀐다.**

## 로그온할 때 알아서 뜨게 — 매번 띄우지 않아도 된다

`자동시작 등록.bat` 을 누른다. 지식시스템 폴더 경로와, 다른 PC에서도 접속하게 할지를 묻는다.
그 뒤로는 **로그온할 때마다 창 없이 알아서 뜬다.** 쓰고 싶을 때 주소만 열면 된다.

- 끄기 — `편집기 끄기.bat`
- 자동 시작 해제 — `자동시작 해제.bat`
- 창이 없으니 메시지는 `_log/server.log` 에 쌓인다. 안 뜨면 여기를 본다

> **윈도우 서비스로 돌리면 안 된다.** `K:` 는 로그온한 사람에게 붙는 EFSS 드라이브라,
> 세션 밖에서 도는 서비스에는 그 드라이브가 보이지 않는다. 그래서 「로그온 시 시작」이다.
> 같은 이유로, **로그오프하면 편집기도 같이 내려간다.** 화면만 잠그면(Win+L) 계속 돌아간다.

## 켜기 — 내 PC에서

`편집기 켜기.bat` 을 두 번 누른다. 브라우저가 알아서 열린다.

```
python server.py
python server.py --port 8778        다른 포트
python server.py --root "D:/사본"    다른 폴더
```

끄려면 검은 창에서 **Ctrl+C**. 창을 닫아도 된다.

파이썬 3.8 이상이면 된다. 설치할 패키지는 없다.

## 팀에 나눠 줄 때 — 각자 자기 PC에서 띄우는 쪽을 권한다

**한 사람 PC를 서버로 쓰면 그 사람이 로그오프·재부팅·절전만 해도 팀 전체가 멈춘다.**
`K:` 는 로그온한 사람에게 붙는 EFSS 드라이브라 서비스로 돌릴 수도 없다.

그래서 기본은 **각자 자기 PC에서 띄우는 것**이다. 잠금을 서버 메모리가 아니라
`K:\...\_편집중` 폴더에 파일로 두는 이유가 이것이다 —
각자 띄워도 **같은 잠금을 본다.** 「○○님이 편집 중」이 그대로 작동한다.

| | 각자 띄우기 (권장) | 서버 한 대 |
|---|---|---|
| 한 명이 꺼지면 | 그 사람만 못 쓴다 | **전원이 못 쓴다** |
| K드라이브 권한 | 각자 본인 계정 | 서버 계정 하나로 뭉뚱그려진다 |
| 준비 | 각자 한 번 등록 | 한 대만 세팅 |

나눠 주는 방법 — 받는 사람은 이 세 가지만 하면 된다.

1. 파이썬 3.8 이상 설치
2. `git clone https://github.com/sookjinroe/proposal-knowledge`
3. 받은 폴더에서 `자동시작 등록.bat` 을 한 번 누른다

그 뒤로는 로그온할 때마다 알아서 뜨고, 코드도 알아서 최신이 된다.
주소는 각자 `http://127.0.0.1:8777`.

## 꺼져도 다시 뜬다 — 지킴이

`watchdog.py` 가 편집기를 띄워 두고, **뜻밖에 꺼지면 다시 띄운다.**
`편집기 켜기.bat` 과 자동 시작은 모두 지킴이를 거친다.

- 자동 갱신으로 새 코드를 받으면 지킴이가 다시 띄운다
- 편집기가 죽으면 5초 → 10초 → … 로 늘려 가며 다시 띄운다
- 잇달아 다섯 번 바로 죽으면 멈추고 그 사실을 기록에 남긴다. 무한히 되풀이하지 않는다
- 이미 켜져 있으면 지킴이는 그냥 빠진다
- `편집기 끄기.bat` 은 지킴이를 먼저 내린다. 안 그러면 꺼도 바로 다시 뜬다

## 켜기 — 서버 한 대에 여러 명이 붙을 때

```
python server.py --host 0.0.0.0 --root "K:/Workgroups/제안전략 지식시스템"
```

그 서버에서 K드라이브가 **마운트돼 있어야** 한다. 접속은 `http://<서버주소>:8777`.

**로그인이 없다.** 망에서 그 포트에 닿는 사람은 누구나 레코드를 고칠 수 있다.
사내망 안에서만 열거나, 앞에 인증 프록시(사내 SSO·리버스 프록시)를 두고 쓴다.
`--host 0.0.0.0` 으로 켜면 서버가 이 경고를 찍는다.

서버가 K드라이브에 쓸 때 쓰는 계정은 **서버를 돌리는 계정 하나**다.
누가 무엇을 고쳤는지는 K드라이브 권한이 아니라 아래 「이름」과 백업으로 남는다.

#### 업데이트 — 아무도 손대지 않아도 된다

서버가 **스스로 최신 코드를 따라간다.** 기동할 때 한 번, 그 뒤로 10분마다 확인한다.

1. `git fetch` 해서 새 커밋이 있는지 본다
2. **편집 중인 사람이 있으면 건너뛴다.** 다음 차례에 다시 본다
3. 받을 게 있으면 `git pull --ff-only` 하고 **스스로 다시 뜬다**
4. 열어 둔 화면은 버전이 바뀐 것을 보고 **알아서 새로 고친다**
   (고치던 중이면 그대로 둔다. 저장하거나 취소한 뒤에 따라간다)

그래서 쓰는 사람은 할 일이 없다. 켜 두면 알아서 최신이 된다.

```
python server.py --host 0.0.0.0 --no-auto-update     스스로 받지 않게
python server.py --host 0.0.0.0 --update-every 1800  30분마다 확인
```

```
python server.py --host 0.0.0.0 --git-timeout 600        프록시가 느릴 때
```

고쳐 둔 파일이 있으면 당기지 않고 건너뛴다. 서버에서는 코드를 직접 고치지 않는 게 좋다.
`git` 으로 받은 폴더가 아니면 자동 갱신은 그냥 꺼진다.

**서버에서 `git` 자격증명이 캐시돼 있어야 한다.** 비공개 저장소라 `git fetch` 가 인증을 요구하는데,
저장된 자격증명이 없으면 로그인 창을 기다리다 타임아웃으로 끝난다.
그러면 자동 갱신이 **영영 아무것도 하지 않는다.**
배포용 PAT 나 deploy key 로 clone 해서 자격증명이 남게 하고,
서버 콘솔에 아래가 찍히는지 한 번 보고 넘어가는 게 좋다.

```
[자동 갱신] GitHub 응답이 300초 안에 안 왔습니다 (연속 3회).
** 자동 갱신이 계속 실패합니다. 프록시나 자격증명을 확인하세요.
```

연속 3회 실패하면 이 경고를 찍는다. 조용히 실패하지는 않는다.

## 이름

편집할 때 다른 사람에게 보일 이름을 한 번 적는다. 머리의 **이름** 단추로 언제든 바꾼다.
브라우저에 저장되고 요청마다 서버로 간다.

이 이름은 **본인이 적는 것이라 신원 증명이 아니다.** 컨플루언스의 「○○님이 편집 중」 과 같은
용도다 — 누가 지금 그 레코드를 잡고 있는지 알리는 이름표.
이름을 적지 않으면 `이름 없음` 으로 잡히고, 그래도 잠금 자체는 정상으로 작동한다.

## 읽기

왼쪽이 K드라이브 폴더 구조다. 레코드를 고르면 **읽기 좋게 그려진 화면**이 나온다.
표·목록·강조가 그대로 보이고, `(확인 필요)` 는 노란색으로 뜬다.

- 들어오면 **아무것도 열려 있지 않다.** 왼쪽에서 고르면 그때 뜬다
- 카테고리는 **접힌 채로 시작한다.** 펼쳐 둔 것은 브라우저가 기억해서
  다음에 들어와도 그대로다. 찾는 중에는 전부 펼쳐지고, 찾기를 끄면 되돌아간다.
  검색 결과를 눌러 들어가면 그 카테고리는 알아서 펼쳐진다
- 맨 위 **CLAUDE.md** 는 작성 규칙 문서다. 눌러서 읽을 수는 있고 **고칠 수는 없다**
- 각 카테고리 맨 위에 그 카테고리의 **양식**이 있다
- 숫자 배지는 그 레코드에 남은 `(확인 필요)` 개수다. `✓` 면 다 찼다
- **새로 읽기** — 편집기 밖에서 파일을 고쳤을 때 누른다

### 「확인 필요」 표시

노란 칠은 따로 저장해 둔 표시가 아니라 **본문의 글자 그 자체**다.
괄호를 열고 「확인 필요」로 시작하면 그 괄호가 닫힐 때까지 노랗게 칠하고, 배지에도 한 건으로 센다.
**칠하는 규칙과 세는 규칙이 같은 하나**라 숫자와 노란 자리는 늘 맞는다.

- 띄어쓰기는 몇 칸이든 없든 같은 것으로 본다 — `(확인 필요)` `(확인필요)` `(확인  필요)` 다 걸린다
- 괄호는 반각·전각 둘 다 — `（확인 필요）` 도 걸린다
- 괄호 안에 괄호가 또 있어도 끝까지 칠한다 — `(확인 필요 — 파일명(확장자 제외) 기재)`
- 닫는 괄호를 빼먹으면 **그 줄 끝까지**로 본다. 숫자만 오르고 칠은 안 되는 일은 없다
- 채워 넣고 저장하면 칠과 숫자가 **같이** 내려간다. 따로 할 일은 없다
- 도구막대의 **(확인 필요)** 단추를 쓰면 글자를 틀릴 일이 없다

### 레코드 만들기·지우기

- 트리의 각 카테고리 맨 위 **「＋ 새 레코드」** — 이름을 적으면 그 카테고리 양식으로 만들고
  **바로 편집 모드로 들어간다.** 양식의 빈 칸은 `(확인 필요)` 로 채워 두니 배지가 정직하다
- 양식에 빠져 있는 필수 필드가 있으면 만들 때 채워 넣는다
  (02 양식에는 「소속 오퍼링·담당자」가, 03 에는 「담당자」가 빠져 있다)
- 지우기는 편집 모드의 **「레코드 지우기」**. **바로 지우지 않고**
  지식시스템의 `_지운것\<카테고리>\<날짜-시각>_<이름>` 으로 옮긴다. 거기서 되돌릴 수 있다
- 남이 편집 중인 레코드는 지울 수 없다. 양식도 지울 수 없다
- 이름에 `\ / : * ? " < > |` 는 쓸 수 없고, `_` 로 시작할 수 없다

## 고치기 — 여러 사람이 쓸 때

**「수정하기」를 눌러야 편집 화면으로 바뀐다.** 누르는 순간 그 레코드를 **잠근다.**

- 잠금은 K드라이브 `_편집중` 폴더에 파일 하나로 남는다.
  서버 메모리가 아니라 공유 폴더에 두는 이유는, **각자 자기 PC에서 띄워도 같은 잠금을 보게** 하기 위해서다.
  서버 한 대로 모아 써도 똑같이 작동한다
- 남이 편집 중이면 「수정하기」가 **「편집 중」으로 비활성**되고,
  누가 언제부터 보고 있는지 알려 준다. 트리에도 ✎ 표시가 붙는다
- **저장하거나 취소하면 잠금이 바로 풀린다.** 창을 닫아도 풀린다
- **15분** 동안 아무 신호가 없으면 끊긴 잠금으로 보고 다른 사람이 가져갈 수 있다
  (PC가 꺼졌거나 브라우저가 죽은 경우)
- 급하면 「잠금 가져오기」로 뺏을 수 있다. 확인을 한 번 묻는다
- 잠금을 쥐지 않은 저장 요청은 **서버가 거부한다.** 화면을 우회해도 안 된다

편집 화면이 따로 있지 않다. **읽던 화면 그대로** 고칠 곳을 누르면 그 자리에서 열린다.

- **표** — 엑셀처럼 **칸**으로 열린다. 행 추가 · 열 추가 · 행 지우기 버튼이 있다.
  파이프(`|`) 문법을 몰라도 된다
- **글(문단·목록)** — **보이는 그대로 고친다.** 마크다운 기호는 화면에 나오지 않는다.
  굵은 글씨는 굵게 보이고, 글머리는 동그라미로 보이고, 거기에 바로 타이핑한다
  - **엔터** 새 항목 · **Tab** 한 단 들이기 · **Shift+Tab** 한 단 내기
  - **Shift+엔터** 항목 아래 설명 줄
  - **Ctrl+B** 또는 위의 **가** 단추로 굵게. **코드** 단추로 파일명·명령어 표시
- **섹션 제목과 「출처」 줄은 눌리지 않는다.** 구조가 흔들리면 다른 도구가 레코드를 못 읽는다
- ` ``` ` 로 묶은 덩어리(조직도 등)도 눌리지 않는다. 줄 모양 자체가 내용이라 합쳐지면 안 된다
- 양식의 `<!-- 안내 -->` 주석은 **흐린 글씨**로 보여 주기만 하고 고칠 수 없다
- **한 번에 한 군데만 열린다.** 다른 곳을 누르면 열려 있던 곳이 먼저 닫힌다
- **「취소」는 그 자리 하나만 되돌린다.** 편집 모드와 잠금은 그대로다.
  고치던 글이 있으면 한 번 묻는다. 아무것도 안 고쳤으면 그냥 닫힌다.
  레코드 전체를 놓으려면 **「편집 끝내기」** 다 — 그래야 잠금이 풀린다
- 저장은 **Ctrl+S**, 취소는 **Esc** 도 된다
- 저장하면 **그 블록의 줄만** 바뀐다. 나머지는 한 글자도 건드리지 않는다
- 블록 안에서도 **고친 자리만** 달라진다. 글머리 기호(`-`·`•`·`·`)와 들여쓴 칸,
  항목 사이의 빈 줄까지 원래대로 돌려 놓는다.
  레코드 128건의 글 블록 724개를 「원문 → 화면 → 원문」으로 돌려 본 결과
  글자가 달라진 블록은 **0건**이다
- 다만 **여러 줄로 접어 둔 문단을 고치면 한 줄로 합쳐진다.** 글자는 그대로다.
  고치지 않고 저장하면 접힌 줄도 그대로 둔다
- 다 고쳤으면 **「편집 끝내기」** 를 누른다. 그래야 잠금이 풀린다

## 저장할 때 막는 것

아래에 걸리면 **저장하지 않고** 무엇이 문제인지 보여 준다.

- 표 칸 값에 줄바꿈이나 `|` 가 들어간 경우 — 그 행부터 표가 깨진다
- 표 칸 값에 `## ` 가 들어간 경우 — 예전에 이것 때문에 레코드가 통째로 깨진 적이 있다
- 필수 필드가 빠진 경우 (01 은 8개, 02 는 4개, 03 은 3개)
- 표의 열 수가 위아래로 어긋나는 경우
- 같은 이름의 섹션이 둘 이상인 경우
- **파일이 편집기 밖에서 바뀐 경우** — 덮어쓰지 않고 새로 읽으라고 한다

## 안전장치

- **잠금 없이는 저장되지 않는다.** 화면이 아니라 서버가 막는다
- 저장 전 원본을 `_백업/<카테고리>/<레코드>/<날짜-시각>.md` 에 복사한다. 레코드당 30개까지 남는다
- 백업은 **이 폴더 안**에 쌓인다. K드라이브 공유 폴더는 더럽히지 않는다
- 손대지 않은 줄은 한 글자도 바뀌지 않는다. 고친 자리만 갈아 끼운다
- `02`·`03` 의 `기준 시점`·`담당자` 를 고치면 그 카테고리 `index.md` 의 같은 칸도 맞춰 준다
- 기본은 `127.0.0.1` 이라 같은 PC 밖에서는 열리지 않는다.
  `--host 0.0.0.0` 으로 켠 경우에만 망에 열리고, 그때는 **로그인이 없다**는 점을 기억해야 한다

## 알아 둘 것

- **첫 기동이 15초쯤 걸린다.** K: 가 네트워크 드라이브라 레코드 125건을 처음 훑는 데 시간이 든다. 그 뒤로는 즉시 뜬다
- 이미 켜져 있는데 또 켜면 **포트를 쓰고 있다**고 알려 주고 멈춘다. 옛 서버로 요청이 새는 것을 막기 위해서다
- `_양식_*` 과 `_기입례*` 는 기본으로 숨겨 둔다. 기입례는 가상 레코드라 제안 근거로 쓰면 안 된다
- `04_회사정보` 의 표는 열이 4개라 칸 편집 대상이 아니다. 섹션 본문으로 고친다
